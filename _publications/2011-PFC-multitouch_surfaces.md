abstract: "El gran auge de las superficies multitáctiles interactivas motiva el desarrollo de este trabajo, que pretende estudiar de abajo a arriba todos los niveles de abstracción, herramientas software y hardware necesarias para conseguir un sistema completamente funcional aplicado a la visualización 3D. En este proyecto se aborda tanto el diseño como la implementación de un sistema software para el uso de mesas multitáctiles de la forma más eficiente y genérica posible, desde tres capas de abstracción: adquisición de datos mediante técnicas de visión artificial, gestión de dichos datos utilizando el protocolo TUIO u otros protocolos, y su integración en aplicaciones arbitrarias. Además se mostrará el desarrollo de un prototipo hardware funcional y se crearán dos paradigmas nuevos de movimiento para la visualización tridimensional, que quedarán integrados con el motor 3D de terrenos y arquitectura digital SANTI."

The project built VideaLAB's infrared, computer-vision multi-touch table from the hardware up: prototype, control software and interaction paradigms for 3D exploration, later used for the [interactive inspection of the Cathedral of Santiago](/publications/2012-VAR-inspeccion_catedral.html) and in a permanent exhibition at the University of A Coruña. The last chapter shows the commercial version of the table and its use by the A Coruña city council to present the municipal urban plans. In Spanish, 160 pages.
